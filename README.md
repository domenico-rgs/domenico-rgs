## Domenico Ragusa
Ph.D. candidate in Computer Engineering focused on complex software systems, high-performance C/C++ applications, real-time processing, and system integration, with applications of AI to medical imaging and biomedical signal analysis.

### 🛠️ Technical Focus
- C/C++ software engineering
- High-performance and real-time systems
- Medical imaging and visualization
- AI for healthcare (signal processing, computer vision)

### 🚀 Selected Projects
- **HSIBrain-Benchmark**  
  Benchmarking framework for the reproducible evaluation of deep learning methods for brain tumour identification in hyperspectral images.
  
- **PCG-Classification-with-NeuralART**  
  Pipeline for the classification of compressed phonocardiogram signals, including neural network optimisation, quantisation, and deployment on STM32 Neural-ART acceleration hardware.

- **ViT-for-Brain-Cancer**  
  Vision Transformer applied to the SLIM Brain dataset for brain tumor detection.

- **HSS-on-RiscV**  
  CNN-based heart sound segmentation on heterogeneous platforms, including RISC-V (AIRISC architecture).
